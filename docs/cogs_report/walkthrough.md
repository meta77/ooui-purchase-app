# 売上原価（レポート）機能 追加完了報告

売上原価（Cost of Goods Sold）を確認できる「レポート」機能の実装および動作検証を完了した。

## 完了した作業
* `mockData.js`: 売上原価計算ロジック（前期末棚卸高 ＋ 当期仕入高 － 当期末棚卸高）を追加
* `router.js`: `/reports`, `/reports/:year` のルーティングを追加
* `AppLayout.vue`: ヘッダーナビゲーションに「レポート」リンクを追加
* `ReportList.vue`: 年度別一覧画面の追加
* `ReportDetail.vue`: 算出過程を確認できる詳細画面の追加
* ブラウザ環境でのUI・計算結果の検証
