## 実装および検証結果

### 1. アプリケーション基盤
- **Vue 3 + Vite + Tailwind CSS v4** を導入し、保守性の高い単一ファイルコンポーネント (SFC) 環境を構築しました。
- `vue-router` を導入し、URLに基づいたビューの切り替えを実現しました。
- ルーティング構造:
  - `/purchases` : 仕入れ一覧
  - `/purchases/:id` : 仕入れ詳細
  - `/products` : 商品一覧
  - `/products/:id` : 商品詳細

### 2. コンポーネント実装
- **AppLayout.vue**: 全ての画面で共通のヘッダーとナビゲーションを提供
- **PurchaseList.vue**: 全ての仕入れを一覧表示するカードレイアウト
- **PurchaseDetail.vue**: 仕入れの概要データと、それに関連する商品 (`Purchase Items`) をリスト表示。商品アイテムから `ProductDetail` への遷移が可能。
- **ProductList.vue**: 商品マスタの一覧表示。
- **ProductDetail.vue**: 商品の単価などの概要と、その商品が購入された履歴 (`Purchase History`) を表示。購入履歴から `PurchaseDetail` への遷移が可能。

### 3. オブジェクト間遷移（OOUI）の確認
実装したモックデータ（`src/store/mockData.js`）を通じて、以下の回遊テストを目視で可能にしています：
1. 「仕入れ一覧」から特定の仕入データ（例: `P-10023`）を選択。
2. 詳細画面で「購入された商品（Purchase Items）」のリストを表示。
3. リスト内の特定商品（例: `カーボンペン`）を選択し、商品詳細へ遷移。
4. 商品詳細画面で「その商品が含まれていた過去の購入履歴（Purchase History）」を表示。
5. 履歴のどれかを選択することで、再び別の仕入れ詳細へ遷移。

これにより、ユーザーが求める「対象（オブジェクト）を起点とした関連情報の探索」が完全に実現されています。
