# OOUI 購買アプリ 実装計画

## 概要
ユーザーが「仕入れ」と「商品」という2つの主要なオブジェクトを起点に関連情報へアクセスできる、完全なオブジェクト指向UI（OOUI）を実装します。

## 設計方針・アーキテクチャ
- 単一の HTML ファイル (`index.html`) 内で Vue 3 と Tailwind CSS を CDN 経由で用いた軽量なモックアップアプリとして実装します。
- 関数と副作用を分離し、データ管理とビューの責務を明確にします。
- コポーネント間はイベントとプロパティにより疎結合を保ち、モックアップでありながら保守性の高い（スケーラブルな）フロントエンドアーキテクチャを目指します。

## ユーザー要望と OOUI ナビゲーション構造
本実装では、以下のオブジェクト間の回遊を可能にします：

1. **Home (起点)**
 ├─ **Purchase List (仕入れ一覧)**
 │      └─ **Purchase Detail (仕入れ詳細)**: 仕入れID, 日付, 合計金額, 商品一覧(Purchase Items)
 │              └─ **Product Detail (商品詳細)** へ遷移可能
 │
 └─ **Product List (商品一覧)**
        └─ **Product Detail (商品詳細)**: 商品ID, 過去の購入履歴(Purchase History)
                └─ **Purchase Detail (仕入れ詳細)** へ遷移可能

## 変更対象ファイル
### `index.html` (軽量モックアップ環境)
- **[MODIFY]** `index.html`: 現在は `Purchase List` のみを描画していますが、画面遷移（コンポーネントの切り替え）ができるように Vue アプリケーションのルート構成を拡張します。

## テスト計画
### 自動/全体構造テスト
- 実装完了後、ローカルブラウザ上で各画面のルーティングが意図通りに動作することを手動確認します。

### 手動検証 (Manual Verification)
1. **仕入れフローの確認**: 「Purchase List」から任意の仕入れアイテムをクリックし、「Purchase Detail」が表示され、その中の商品がリスト表示されるか検証。
2. **商品フローと回遊性の確認**: 「Purchase Detail」内の商品から「Product Detail」へ遷移できるか。さらに、そこから過去の「Purchase Detail」へ飛べるかを検証。
